# Rewşan Reklam Baskı Çözümleri Web Sitesi

Bu klasör GitHub Pages için hazır statik web sitesidir.

## GitHub'a Yükleme

1. GitHub'da yeni bir repository oluşturun.
2. Bu klasörün içindeki dosyaları repository'nin ana dizinine yükleyin:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/`
   - `.nojekyll`
3. GitHub'da repository sayfasında `Settings` bölümüne girin.
4. Sol menüden `Pages` bölümünü açın.
5. `Build and deployment` altında şu ayarları seçin:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. `Save` butonuna basın.

GitHub birkaç dakika içinde site linkini verir.

## Önemli

Dosyaları `rewshan-site` adlı klasörün içinde değil, repository'nin ana dizinine koyun. Yani GitHub'da `index.html` ilk görünen dosyalardan biri olmalı.

## Düzenleme

Ürün isimleri ve metinler `index.html` ve `script.js` içindedir. Tasarım renkleri ve görünüm `styles.css` dosyasındadır. Ürün fotoğrafları `assets/frames/` klasöründedir.
